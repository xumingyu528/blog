## Nmap 主机探测

基础用法，包含ARP、ICMP、TCP、UDP ping 扫描。  

一些常用参数：

* -sn
  	host discovery only
* -n
  	no DNS lookup
* -R
  	Reverse DNS lookup
* ARP 
  -PR
* ICMP
  -PE
  	Echo
  -PP
  	timestamp
  -PM
  	mask
* TCP
  -PS 
  	TCP SYN Ping
  	default 80 port
  	privileged user don't need 3th handshake
  -PA
  	TCP ACK Ping
  	default 80 port
  	privileged user don't need 3th handshake
* UDP
  -PU
  	UDP Ping
  	uncommon port
  	





## Nmap 基础端口扫描

TCP connection 、TCP SYN 、UDP 扫描



### TCP Scan

Nmap 支持不同类型的端口扫描，与 TCP 的6个标志位有关：

* URG
* ACK
* PSH
* RST
* SYN
* FIN



#### TCP connect scan

### 端口调整

#### 端口范围

-p 参数修改端口范围  

```bash
## 扫描22、80、443端口
-p22,80,443

## 扫描1-1023端口
-p1-1023

## 扫描所以端口，从1-65535
-p-

## 扫描常见的10个端口
--top-ports 10
```



#### 扫描间隔

-T 参数指定扫描时间，后面跟0~5的数字，分别代表不同等级，-T0 是最慢，-T5 是最快，man 手册中解释的6种等级：

* paranoid(0)
* sneaky(1)
* polite(2)
* normal(3)
* aggressive(4)
* insane(5)



为了避免触发 IDS 告警，0或者1等级比较适合。  

也可以使用 `--min-rate <number>` 和 `--max-rate <number>` 指定速率，例如指定每秒不超过10次使用 `--max-rate 10` 或者 `--max-rate=10` 。  



#### 并发数量

`--min-parallelism <numprobes>` 和 `--max-parallelism <numprobes>` 指定同时发出的探针数量
